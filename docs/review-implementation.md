# November 2026 review resolutions

The release keeps the app private, static, offline-capable, and available in all five locales. No production dependencies were added. The findings below refer to the application review's F01–F28 identifiers.

| Finding | Resolution                                                                                                                                                                                                                                                            |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F01     | Locale-aware decimal drafts keep their original numeric meaning and full saved precision. Settings income, Cost prices, and bill fields use the same conversion boundary.                                                                                             |
| F02     | Web Locks serialize writes. Each tab rebases its changes onto the latest saved records; bill months merge individually. Storage events refresh other tabs and propagate resets. An open settings draft survives an external preference change and is rebased on Save. |
| F03     | Fixed costs are due only within their inclusive first/last payment months. Current costs sort ahead of scheduled and ended costs.                                                                                                                                     |
| F04     | Valid bill values persist while typing. Blur formats the value and marks incomplete input instead of acting as the only save boundary.                                                                                                                                |
| F05     | Changing the dataset currency requires explicit confirmation that all records are relabeled without exchange conversion.                                                                                                                                              |
| F06     | Monthly budgeting and the chart use the average of recorded monthly totals in the last twelve months. A blank month is unknown, not a zero. Per-bill comparisons retain their own recorded-month averages.                                                            |
| F07     | Zero is a valid bill entry; blank removes the entry.                                                                                                                                                                                                                  |
| F08     | Monthly/yearly salaries are allocated over actual scheduled paid hours in the calendar month. Daily earnings use that same rate. Hourly/weekly pay retains a constant hourly rate and a calendar-specific monthly target. The rate table is labeled as averages.      |
| F09     | The continuous total is explicitly a 24-hour pay equivalent, rather than actual work earnings.                                                                                                                                                                        |
| F10     | Cost offers an explicit pay-left-after-bills scenario, including a no-disposable-pay state. The original total-income equivalent remains the default.                                                                                                                 |
| F11     | Page navigation returns to the top; keyboard navigation focuses the new page heading. Browser Back uses the same behavior.                                                                                                                                            |
| F12     | Cost uses stable headline and supporting-content regions across units and locales.                                                                                                                                                                                    |
| F13     | Masking reserves the summary, per-day, repayment and monthly-target spaces without exposing hidden amounts to screen readers.                                                                                                                                         |
| F14     | Monthly totals are present before the first entry, including zero costs and the income still available. Adding an item does not insert summaries above existing controls.                                                                                             |
| F15     | Missing-month actions stay below the amount-entry region, so month changes do not insert a reminder above the focused fields.                                                                                                                                         |
| F16     | Inline error slots preserve the bill-entry rows. Other form errors use the space between fields.                                                                                                                                                                      |
| F17     | Chart selection distinguishes taps and horizontal intent from vertical page scrolling and pointer cancellation.                                                                                                                                                       |
| F18     | Direct section jumps, bill entry before a collapsed chart, and desktop columns keep fixed costs accessible.                                                                                                                                                           |
| F19     | Empty sections use specific Add bill / Add fixed cost actions. Monthly's empty totals remain useful budget information.                                                                                                                                               |
| F20     | Payment dates are revealed by an explicit Track payments control.                                                                                                                                                                                                     |
| F21     | On-device JSON export and validated import are available before setup and from Settings. Import previews record counts and requires confirmation before replacing data.                                                                                               |
| F22     | The month picker exposes every retained historical bill month; the chart remains focused on the last twelve months.                                                                                                                                                   |
| F23     | Work schedules support overnight shifts, unpaid-break minutes, and weekday-specific hours. Overlapping shifts are rejected. A break's duration is spread proportionally through its shift for live estimates because no break-start time is collected.                |
| F24     | Light-theme chart colors meet the graphical contrast target against their surface; an expandable visible data table provides a color-independent alternative.                                                                                                         |
| F25     | Validation stores translation keys and follows the selected language.                                                                                                                                                                                                 |
| F26     | A branded loading shell is visible before locale copy loads. Service-worker readiness uses a load-state subscription that also handles load completing before React subscribes.                                                                                       |
| F27     | The setup heading states the work-time purpose. On this device exposes privacy and data controls before entering income.                                                                                                                                              |
| F28     | Desktop Earnings uses a card grid, and Monthly places bills beside fixed costs. Cost retains its focused column.                                                                                                                                                      |

Structural risk checks use measured Istanbul coverage after verification rather than estimating test coverage from references. Existing coverage and complexity thresholds remain in place. Screenshot tests use the installed DejaVu Sans as a Linux test fixture; the application continues to use each device's system font.
